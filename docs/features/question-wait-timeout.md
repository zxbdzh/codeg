# 提问等待时长（本地扩展）

对应上游需求： https://github.com/spacering-net/codeg/issues/999

## 使用

在「设置 → 协作 → 会话内工具」的「向用户提问」下设置等待时长：

- **永久等待**（默认）：Codeg 不设置答题期限，数据库值为 `0`。
- **自定义**：输入 `1–10080` 的整数分钟数（最多 7 天）。

保存后适用于新注册的问题，已有问题沿用注册时的期限。仅切换提问工具开关不会重置等待时长。配置保存在应用数据库的 `question.enabled` 和 `question.timeout_minutes` 中，桌面和 Web 共用校验、持久化及运行时配置。

## 生命周期与边界

- 有限期限到期后，按问题 ID 取消等待并清除卡片，不会清除同一连接中后来出现的新问题。
- 用户回答、跳过、停止会话、连接断开或代理主动撤回仍按原有规则结束等待。永久不意味着退出应用后继续挂起请求。
- **永久等待仅表示 Codeg 不主动计时取消，不保证外部智能体宿主无限等待。** 宿主的硬性工具调用期限、会话退出和主动取消仍有效；本功能不修改全局代理环境变量或覆盖用户已有的宿主超时设置。
- 对携带合法 `_meta.progressToken` 的 `ask_user_question` MCP 调用，伴生程序每 60 秒发送 `notifications/progress`，表明仍在等待用户。无 token 时不发送；调用结束后停止。通知有助于支持该机制的宿主区分等待与失联，但不能延长其硬性期限。
- 因此，本扩展提供等待策略配置与进度通知，但不宣称在所有代理和版本中彻底消除 Issue #999 所述超时。
