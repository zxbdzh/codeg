# 手机工作区适配

手机端不展示桌面标签栏，需要提供不依赖键盘、右键或悬停的会话切换入口。

## 交互

- 顶栏的标签页按钮显示已打开数量，打开底部面板，按会话、文件与预览分组。
- 点一行切换标签并关闭面板；行尾关闭按钮只关闭对应标签，沿用现有运行时与未保存文件处理。
- 切换本身不关闭会话、不重新创建连接；启用 Pane 后列出当前 Pane 中所有项目、所有标签页组的会话。
- Android 返回键先关闭标签面板，保持在工作区内。
- 辅助面板页签保持固定触控宽度，内容过多时可左右滑动。

## 窄屏布局

- 手机只在模型按钮上显示模型名称；推理强度、权限和其他设置仍在同一个设置面板完整展示。
- 会话标题右侧的 AI 标签建议入口移入既有更多菜单，长项目名称限制占宽。
- 输入区附件、收藏、发送、停止等入口扩大触控范围；长路径允许换行。
- 手机输入区使用 `min(15rem, 40dvh)` 限制高度，并保留最小编辑高度；收藏弹层限制在屏幕内。
- 软键盘压缩可见区域时，工作区跟随 VisualViewport 高度和偏移；双指缩放不反向修改布局。
- 桌面端保持原有设置摘要、标签栏和控件尺寸。

## Pane 与分屏

- 手机只显示当前会话并占满会话区，不显示分屏标签栏、分割线或聊天宽度拖柄，也不横向平铺多个会话。
- 仅改变本机呈现方式；桌面共享的分屏树、比例、平铺设置和会话归属保持不变。隐藏的会话继续挂载，切换不停止任务。
- 触屏设备宽度小于 1024px 时继续采用手机布局，覆盖手机横屏；鼠标设备仍使用原有的 768px 分界。
- 手机灵动岛位于独立的紧凑行中，避免覆盖会话标题或顶栏按钮。点按展开、选择或新建后收起，按钮至少 44px，不依赖悬停。
- 每个 Pane 都有可直接点按的操作菜单，支持重命名和移除。名称较多时横向滚动，展开后自动露出当前 Pane 及其操作按钮。
- 移除带有未发送内容的 Pane 需要确认；最后一个 Pane 不能移除。移除当前项后会解除菜单展开状态，不会留下无法收起的切换栏。
- 浏览器返回先处理灵动岛、菜单或确认框，保持在工作区。切换到文件预览时，会话编辑器及草稿仍保留。

- 11 个相关测试文件、112 项测试通过，包含 Pane 状态、手机切换、宽度拖柄、编辑器保活、返回栈及 Web App 安装；受影响文件的 ESLint、格式和生产构建通过。
- 使用 Ego 的独立 TaskSpace 与隔离服务器验收最终生产静态资源。320、375、390、430、767px 竖屏，844×390 横屏及 390×420 短屏都仅显示一个全宽会话，没有分屏拖柄或页面横向溢出；1280px 鼠标视口恢复桌面分屏。
- 同时存在分屏和平铺时，手机仍仅显示选中的会话。同一组和不同组之间可通过标签面板切换；共享分屏树、比例和平铺设置保持。
- 实际触摸事件覆盖灵动岛展开、新建、重命名、移除和横滑。八个长名称 Pane 时自动露出当前项，控件保持约 44px 触控高度。
- 来回切换会话及 Pane 后，同一编辑器节点和未发送草稿保留，没有发出停止或断开请求。带草稿移除确认、返回取消、最后一个 Pane 禁止移除及移除当前项后的收起均通过。
- 用固定测试消息补充长回复、长路径、代码块和表格渲染检查；仅替换会话 `turns`，未注入样式或替换界面。应用运行错误为零；快速改变视口时捕获到两次浏览器 ResizeObserver 通知，属根布局已有专门处理的通知类型，不计作系统安装或真机验收。

- 320、375、390、430 像素宽度无页面横向溢出，标签面板在屏幕内，顶栏按钮至少 40px。
- 两个会话可以切换，浏览器返回先关闭标签面板，不离开工作区。

模型设置弹层由组件测试覆盖，本轮独立运行时未就绪，未声称完成其浏览器实测。文件切换和关闭保护复用已有动作，并由组件测试覆盖；未发送模型请求、未验证附件上传的后端链路。
模拟可见高度变化不能替代 Android/iOS 真机输入法、浏览器地址栏和系统返回手势的最终确认。

## 构建约束

Tailwind 的 PostCSS 扫描基目录固定到 `src`，第三方 json-render 组件继续通过现有 `@source` 显式包含。不能恢复为整个仓库扫描：Webpack 会把返回的目录依赖递归做快照，读取 `src-tauri/target` 中的大型二进制和安装包，导致构建内存暴涨。历史缓存还可能保留旧样式，验收时必须检查导出的 CSS 和实际触控尺寸，不能仅凭构建命令成功判断。
