# 在 Codeg 内集成 Ego 的真实页面

用户希望在 Codeg 内直接查看和操作 Ego 的真实页面，选择页面级集成：Codeg 提供地址栏与标签页，页面由执行端的原版 Ego 运行。用户看到的内容、手动输入和 Agent 操作均对应同一个 Ego 页面及其当前状态。

该选择使浏览器能够与代码、终端和对话共同组织在 Codeg 工作区中，同时保留原版 Ego 作为实际浏览器。曾考虑展示完整 Ego 窗口，包括其地址栏、标签页和 Space 界面；用户选择由 Codeg 承担页面组织与展示。

同一页面是验收约束：已有登录、表单内容和导航状态必须连续，人工操作结果须能被 Agent 在该页观察到。

人工接管采用用户已确认的“操作即接管”：仅观看页面不影响 Agent；用户点击或输入时，先暂停相关 Agent 浏览器操作，再交付人工输入。Agent 只能在用户显式点击“交还 Agent”后继续，不因空闲超时、页面失焦或重连自动恢复。该选择支持直接操作页面，同时让恢复时机由用户掌握。

每条 Codeg 会话拥有独立的浏览器页面组。人工接管暂停所属页面组的自动化，其他会话的页面组可继续；显式交还也仅恢复这一组。相较于按项目或全局共用页面，该选择让页面与会话的归属清楚，并将接管影响限制在当前会话。

同一页面组允许多端观看，同时只有一个人工操作端。已有人工操作端时，新设备须点击“接管到此设备”才能获得控制，原设备随即变为只读，无需原端确认；原端断线也不阻止切换。用户选择显式切换，避免另一端误触就转移控制权。

设备切换期间，该组的 Agent 浏览器操作保持暂停，只有当前操作端显式点击“交还 Agent”后才继续。失去控制权的原端只能观看，重连不自动取回控制权。没有其他人工操作端占用时，仍按既定规则由点击或输入自动接管 Agent。

各会话页面组共用用户当前 Ego 的网站登录态，不按项目或会话另建独立登录要求。用户选择直接复用已有登录身份，同时明确保留按会话独立的页面归属和接管范围；共享登录态不会将这些页面组合并。

一轮任务完成后，保留所属会话页面组中的页面，直到用户主动关闭；下一轮继续使用原来的实际页面及其当前状态。用户选择保留全部任务页面供检查和继续操作，接受按需主动清理页面，而不采用只保留结果页或任务结束后自动清理的策略。

关闭 Codeg 中的页面标签会真正关闭执行端对应的 Ego 页面，成功后其他设备同步移除该页。用户选择让标签关闭与实际页面生命周期一致，避免关闭入口后页面仍在后台积累；该动作只影响对应页面，不关闭同组或日常 Ego 的其他页面。

若 Agent 正在操作，先暂停所属页面组，再关闭页面，直到用户显式点击“交还 Agent”后才继续。交还前不自动重建被关闭的页面；交还后依据页面已关闭的真实状态继续。关闭动作遵守已有的人工控制权规则，失去控制权的只读端须先显式接管。

上述原页保留约束以 Ego 正常运行为前提；适配须遵守该约束，不能直接套用原版指南的任务结束清理流程。注销或系统重启后，用户人工重新登录并启动 Codeg、Ego；保留会话、仍需保留的页面地址及已完成下载，页面可按地址重开，不保证原有表单等临时状态。用户已主动关闭的页面不因恢复重新出现。

关闭 Codeg Web 或网络断开后，正在自动执行的浏览器任务继续在执行端运行，重新连接时回到原会话、仍存在的实际页面和最新进度。用户选择让任务持续执行，避免临时网络波动或关闭网页打断开发；Web 连接结束不构成任务结束或页面清理条件。

已经人工接管的页面组仍保持暂停，直到用户显式点击“交还 Agent”。断开和重连不会自动恢复该组，也不会改变其人工接管状态。Web 断线后继续运行的决定以 Windows、Codeg 和 Ego 执行端正常运行为前提；首版保持 Windows 登录且未锁屏，锁屏不列入保证范围，详见 ADR 0007。

注销或重启后人工恢复环境的场景中，任务需等待用户确认才继续，已有人工接管状态仍需显式交还；重新启动应用不能视为用户已同意恢复任务。该恢复目标与单纯 Web 断线后的持续运行分别验收。

首版包含完整的 Web 文件往返：网站上传可选择当前电脑或手机上的文件，也可选择执行端已有的项目文件；网站下载保留在执行端，按 Codeg 会话展示，并允许从 Web 取回当前设备。用户选择将临时素材上传和结果取回纳入同一工作流，接受相应的文件传输适配范围，不采用首版仅支持执行端文件的方案。

向网站交付文件仍遵守页面组接管及多端人工控制规则。该选择确认来源、归属与取回体验，具体存放位置、传输实现、清理策略和中断恢复仍需技术设计与验证。

首版允许明确的系统弹窗例外：对于确实无法通过 Ego 页面通道或现有 computer use 处理的系统弹窗，Web 提示阻塞原因，由用户在执行机处理后回来继续。网页内交互、文件选择和已有 computer use 继续按已定范围提供；既有人机交接、授权和停止规则不因此改变。该例外的运行范围见 ADR 0007。

本 ADR 记录用户确认的范围。2026-11-15 的工作树已采用会话到原版 Ego TaskSpace 的映射、本机 CDP 页面画面和输入、带 epoch 的人工归属及持久视图映射，并复用桌面 computer use 服务。独立后台 profile 的技术实验已取得同页交互、暂停交还、多端转移、文件往返和桥接恢复证据；当前日常 profile 与实际无显示器整体验收尚未完成。详细实现与 V1–V11 阶段性证据见 [验收记录](../features/remote-development-ego.md#当前阶段首版实现与集成验收)。
