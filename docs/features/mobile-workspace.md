# 手机工作区

手机布局适用于小于 768px 的屏幕，以及小于 1024px 的触屏设备，覆盖手机横屏。

- 顶栏提供已打开标签页的面板，按会话、文件和预览分组；可以直接切换或关闭标签。
- 浏览器返回优先关闭标签面板、灵动岛和相关弹窗。
- 会话区始终只显示一个全宽会话，隐藏桌面分屏、平铺布局和宽度拖柄。
  其他会话继续挂载，桌面布局和未发送内容保留。
- 辅助面板页签保持触控宽度，可以横向滚动。
- 输入区扩大主要按钮的触控范围，只在模型按钮上显示模型名称；
  其他会话设置仍可在同一个面板中修改。
- 编辑器最大高度随可见视口调整，避免短屏和软键盘挤掉操作按钮。
- 工作区跟随 VisualViewport 的高度和偏移，双指缩放不反向修改布局。
- 可选的多项目灵动岛使用独立行及可点按的操作菜单，不依赖右键或悬停。

## 验证范围

组件与状态测试覆盖标签切换、单独关闭、文件预览、编辑器保活、VisualViewport
变化，以及灵动岛的点按、键盘操作和草稿移除确认。浏览器设备模拟不能替代
Android/iOS 真机上的输入法、系统返回手势和安全区验证。
