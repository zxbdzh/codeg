# Pane 跨项目组合会话，导航遵循唯一归属

Pane 是一套可切换的中央会话区工作布局，各自管理会话、标签页组及其分屏排列。同一个 Pane 可以包含不同项目的会话，已打开的会话同一时间只归属一个 Pane，尚未打开的会话可以没有归属。

会话区始终按当前 Pane 组织，切换项目不隐藏其中其他项目的会话。现有“标签页跟随文件夹”设置继续作用于文件页签，不再过滤 Pane 中的会话。

从会话列表打开已归属其他 Pane 的会话时，切换到其所属 Pane 并激活会话，保留已有布局。关闭会话标签页后解除归属，下次从会话列表打开时加入当前 Pane。对仍然打开的会话，只有显式移动操作才改变归属，避免日常导航打乱用户安排好的工作内容。

切换 Pane 只改变当前显示的工作布局，原 Pane 中正在执行的会话任务继续在后台运行。停止任务由用户单独操作，不随 Pane 切换发生。

移除 Pane 时关闭其中的会话标签页并解除归属，保留历史会话和正在后台执行的任务。下次打开这些会话时加入当前 Pane，停止任务仍须用户单独操作。

桌面端和 Web 端连接同一个 Codeg 服务时，Pane 名称、会话归属和分屏布局保持一致，而非分别维护各客户端的独立布局。

用户要求在独立查看位置会增加复杂度时优先采用简单方案。现有已持久化会话的选中状态已经跨端同步，因此本次让当前 Pane 和选中的已持久化会话也联动，沿用现有本机草稿保护，不额外拆分每个窗口的独立查看位置。

## Considered Options

- **每个 Pane 限定一个项目**：项目边界直接，但不能表达用户截图中的跨项目组合。
- **同一会话同时出现在多个 Pane**：可以复用视图，但不符合用户要求的会话唯一归属。
- **打开会话时自动移入当前 Pane**：可以留在当前工作面，但会在普通导航中改变已有布局。
- **关闭标签页后保留原 Pane 归属**：可以固定工作内容，但用户选择关闭即解除归属，让下次打开的位置由当前 Pane 决定。
- **只在客户端本地保存 Pane 和分屏**：可以延续现有分屏的存储方式，但无法满足用户要求的同服务桌面端与 Web 端一致性。
- **共享布局、各窗口独立查看位置**：便于多窗口分别查看，但需要额外拆分选中状态、恢复逻辑和远端变更后的回退；按用户优先简单的条件，本次不采用。

## Consequences

- 项目文件夹与 Pane 是独立的组织关系，不能以项目文件夹作为 Pane 的上层容器。
- 本次 Pane 只管理会话区，文件页签与终端沿用现有组织方式，不纳入各 Pane 的保存和切换。
- 唯一归属约束针对已打开的会话，不要求所有历史会话始终归属某个 Pane。
- 切换和移除 Pane 均不能自动停止会话任务，任务的执行生命周期与 Pane 的显示和存在状态分离。
- Pane 名称、会话归属和分屏布局需要同一服务下的共享持久状态，不能仅依赖单一客户端的本地存储。
- 一端切换 Pane 或选中已持久化会话时，其他端会联动；保留现有本机草稿保护。
- 具体实现与验收范围见 [Pane 功能记录](../features/pane-layouts.md)。
