# 小鲸鱼余额挂件

## 已确认

- 小鲸鱼和余额气泡显示在 Codeg 窗口内，最小化窗口时一起收起。
- 沿用参考挂件的读数：标题为账户名称加「余额」，下一行显示 `{balance} · 已用 {used}`。两项保留两位小数，省去「算力」单位和总量。
- 数字来自余额服务，代表账户额度，与 Codeg 单次会话的 token 统计分开。

- 所有代理的聊天都显示同一个账户的小鲸鱼。切换项目或会话时沿用同一读数。
- 在 Codeg 配置一次余额服务，由 Codeg 独立查询。关闭 DSH 后仍可更新。
- 电脑默认展开气泡。手机默认收起，只显示鲸鱼，轻点后查看余额。

## 实施建议

- 查询凭据只由后端持有；远程浏览器通过 Codeg 的认证链路取得显示字段。
- 查询失败时保留上次成功的读数，并标明更新时间。首次查询尚无结果时显示「—」，真实零余额显示 `0.00`。
