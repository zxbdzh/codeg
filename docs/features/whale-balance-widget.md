# 小鲸鱼余额挂件

## 已确认

- 小鲸鱼和余额气泡显示在 Codeg 窗口内，最小化窗口时一起收起。
- 沿用参考挂件的读数：标题为账户名称加「余额」，下一行显示 `{balance} · 已用 {used}`。两项保留两位小数，省去「算力」单位和总量。
- 数字来自余额服务，代表账户额度，与 Codeg 单次会话的 token 统计分开。

- 所有代理的聊天都显示同一个账户的小鲸鱼。切换项目或会话时沿用同一读数。
- 在 Codeg 配置一次余额服务，由 Codeg 独立查询。关闭 DSH 后仍可更新。
- 电脑默认展开气泡。手机默认收起，只显示鲸鱼，轻点后查看余额。

## 可自定义的内容（P0 范围）

设置入口：**设置 → 通用 → 小鲸鱼余额挂件**。桌面与 Web（服务器模式）共用同一份配置。

| 分组 | 可配置项 |
| --- | --- |
| 余额来源 | 多个模型账户；每个账户独立配置账户名、接口地址、请求方法、请求头模板、密钥、`remaining` / `used` / `total` / `unit` 字段路径、数值倍率 |
| 厂商模板 | 选择常用余额/订阅额度厂商，一键填入接口与响应字段路径 |
| 轮询 | 轮询间隔（15–3600 秒），后端独立轮询，与前端是否打开无关 |
| 峰谷价格 | 高峰单价、低谷单价（每百万 token）、币种 |
| 气泡展示 | 是否显示余额、接口已用、今日观测消费、预估 token 费用；挂件头像尺寸（32–96 px） |
| 余额校正 | 为当前模型增加或扣除校正值，与接口返回的「已用」分开记录 |
| 挂件交互 | 拖拽后吸附到工作区四边，底边贴在状态栏上沿；调整窗口或挂件大小后仍保持贴边。菜单可切换镜像，位置与镜像在本地记住 |
| 独立挂件配置 | 气泡模块、随机内容、图片/音效素材、事件提醒、阈值、额度与模型单价单独保存，不与旧余额/展示 KV 混写 |

## 口径

- **接口已用**：余额接口自己返回的 `used` 字段，取不到时留空，不显示为零。
- **今日观测消费**：只累加「余额下降」的观测差，按模型分别记账。充值（余额上升）单独记录，不会冲掉当天已消费的金额；单位/币种切换造成的跳变只重置基准。
- **预估 token 费用**：按 Codeg 已记录的逐轮 token 数乘以每百万 token 单价估算，高峰时段为北京时间工作日 09:00–12:00、14:00–18:00，周末全天按谷价。未填写单价时该项留空，不显示 `0.00`。
- 三项数值互相独立，任何一个缺失都不影响其余项的显示。

## 实施建议

- 查询凭据只由后端持有；远程浏览器通过 Codeg 的认证链路取得显示字段。
- 查询失败时沿用上次成功的读数，并标明更新时间。首次查询尚无结果时显示「—」，真实零余额显示 `0.00`。
- 配置、快照、账本、展示偏好四项分别存于 app metadata KV（`whale_balance.config` / `.snapshot` / `.ledger` / `.presentation`），写入走单个事务，避免配置与快照只更新一半。
- 账本分两层：逐条明细（上限 5000 条，超出丢最旧）与按模型/日期的消费聚合（保留 400 天）。今日消费读聚合表，所以明细被裁剪也不会少算；旧账本首次读取时从明细回填聚合。
- 旧的单账户配置在首次读取时自动包装成 `default` 模型，密钥随迁移保留，不需要重新填写。
- 头像使用 `public/images/whale-widget.png`，显示尺寸由「挂件大小」控制（32–96 px）。
- 独立挂件配置存于 `whale_balance.widget_options`。用户导入的图片和音频以 base64 保存，不复制原挂件素材。
- 气泡编辑支持模块占位符、随机内容、加权序列、排版、颜色字体、图片和模块库；事件支持按压、完成、提问、授权、余额不足、预算上限，可配置音频、音量、持续时间和提醒泡泡。
- 余额快照在前端每 30 秒自动刷新；提醒与用量窗口按事件或打开时的数据源刷新。
- 用量窗口包含 Codeg 本地会话统计与最近 `rate_limits` 快照。Codex 订阅窗口只在日志有可用主/次窗口时显示，不伪造 5h/周/月数据。
