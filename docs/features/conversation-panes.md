# 多项目灵动岛

在「设置 → 常规 → 多项目灵动岛」开启，默认关闭。该开关保存在当前设备，
同一浏览器或桌面应用的其他设置窗口会同步更新；其他设备可以分别选择是否启用。

Pane 是一套命名的会话工作布局，保存会话归属、标签页组、分屏排列和平铺设置。
同一 Pane 可以容纳不同项目的会话。文件页签和终端仍沿用原有组织方式。

- 桌面端中央顶部的胶囊靠近或聚焦时展开，离开后收起，不推动会话内容。
- 手机端使用独立紧凑行，点按展开，操作按钮至少 44px；名称过多时横向滚动。
- 可以新建、重命名和移除 Pane；最后一个不能移除。
- 会话标签的右键菜单提供「移动到 Pane」，移动后自动切换到目标。
- 从列表打开已经打开的会话，会切到它所属的 Pane。
- 切换 Pane 保留后台会话。移除只关闭标签页，不删除历史或停止正在运行的任务。
  移除含未发送内容的 Pane 前会提示确认。

开启后，Pane 名称、会话归属、布局及选中的已持久化会话通过现有标签页接口同步到
连接同一服务的客户端。未发送草稿仍保存在本机。关闭开关恢复普通标签页和原有
「标签页跟随文件夹」行为，保留 Pane，重新开启可继续使用。

## 持久化与兼容性

`list_opened_tabs`、`save_opened_tabs` 和 `tabs://changed` 共用原有版本及事务，
新增可选 `pane_state`；保存命令参数使用 `paneState`。缺省字段兼容已有客户端。
服务端校验唯一归属、布局结构和引用；过期版本返回当前快照，不覆盖较新的写入。
级联删除和会话移动同步清理或重映射 Pane 中的会话标识。

关闭功能时不启用 Pane 视图，也不把其他客户端同步来的 Pane 强行切到前台。
移动端只投影当前会话，不修改共享的桌面分屏与平铺布局。
