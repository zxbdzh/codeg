# 手机工作区适配

手机端不展示桌面标签栏，需要提供不依赖键盘、右键或悬停的会话切换入口。

## 交互

- 顶栏的标签页按钮显示已打开数量，打开底部面板，按会话、文件与预览分组。
- 点一行切换标签并关闭面板；行尾关闭按钮只关闭对应标签，沿用现有运行时与未保存文件处理。
- 切换本身不关闭会话、不重新创建连接；标签范围沿用“跟随文件夹”偏好。
- Android 返回键先关闭标签面板，保持在工作区内。
- 辅助面板页签保持固定触控宽度，内容过多时可左右滑动。

## 窄屏布局

- 手机只在模型按钮上显示模型名称；推理强度、权限和其他设置仍在同一个设置面板完整展示。
- 会话标题右侧的 AI 标签建议入口移入既有更多菜单，长项目名称限制占宽。
- 输入区附件、收藏、发送、停止等入口扩大触控范围；长路径允许换行。
- 手机输入区使用 `min(15rem, 40dvh)` 限制高度，并保留最小编辑高度；收藏弹层限制在屏幕内。
- 软键盘压缩可见区域时，工作区跟随 VisualViewport 高度和偏移；双指缩放不反向修改布局。
- 桌面端保持原有设置摘要、标签栏和控件尺寸。

## 验证

组件测试覆盖会话切换、单独关闭、文件切换、活动文件标记、手机模型摘要，以及软键盘高度变化、平移、双指缩放和退出手机布局后的清理。

2026-11-13 的无窗口 Chromium 验证使用独立测试目录和生产静态资源，未注入替代样式：

- 320、375、390、430 像素宽度无页面横向溢出，标签面板在屏幕内，顶栏按钮至少 40px。
- 两个会话可以切换，浏览器返回先关闭标签面板，不离开工作区。
- 触摸事件验证了打开、切换和关闭；关闭非当前标签后，当前会话保持不变。
- 辅助面板 10 个页签保持至少 44px 宽，横向可滚动。
- 模拟可见高度降至 420px 时，工作区同步缩短。
- 320px 下输入长路径仍可换行，输入区操作按钮 40px，收藏弹层不越界；1280px 下恢复桌面布局及 32px 发送按钮。

相关 13 个测试文件共 218 项通过，受影响文件的 ESLint、格式检查和生产静态导出通过。浏览器使用旧版测试后端配合本轮前端资源，版本提示在触摸验收前关闭，不能将本轮结果视为完整的前后端发版验收。

模型设置弹层由组件测试覆盖，本轮独立运行时未就绪，未声称完成其浏览器实测。文件切换和关闭保护复用已有动作，并由组件测试覆盖；未发送模型请求、未验证附件上传的后端链路。
模拟可见高度变化不能替代 Android/iOS 真机输入法、浏览器地址栏和系统返回手势的最终确认。

## 构建约束

Tailwind 的 PostCSS 扫描基目录固定到 `src`，第三方 json-render 组件继续通过现有 `@source` 显式包含。不能恢复为整个仓库扫描：Webpack 会把返回的目录依赖递归做快照，读取 `src-tauri/target` 中的大型二进制和安装包，导致构建内存暴涨。历史缓存还可能保留旧样式，验收时必须检查导出的 CSS 和实际触控尺寸，不能仅凭构建命令成功判断。
